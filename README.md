# DecodeLabs Task 3 - Interactive Portfolio Website

## Overview
This project is an Interactive Portfolio Website developed during the DecodeLabs Frontend Development Internship.

The website combines HTML, CSS, and JavaScript to create an interactive user experience through dynamic content updates and user interactions.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Interactive portfolio layout
- Dark Mode toggle
- Dynamic heading updates
- Show/Hide Skills section
- About Me content toggle
- Interactive buttons using JavaScript
- DOM manipulation and event handling

## Learning Outcomes
- JavaScript fundamentals
- DOM manipulation
- Event listeners
- Dynamic content updates
- User interaction handling

├── index.html
├── style.css
└── script.js
